# The Rose Room — Venice Beach

An editorial event-venue website for The Rose Room at 6 Rose Avenue in Venice, California.

Production: https://rose-room-venice.vercel.app

## Deployment

This is a buildless static website prepared for Vercel. No dependency installation or build command is required.

- Framework preset: Other
- Build command: Leave blank
- Output directory: Leave blank
- Root directory: Repository root

## Local preview

Serve the repository root with any static HTTP server and open `index.html`.

## Image sources

The site uses Rose Room brand material and venue imagery sourced from the business's existing website, Instagram presence, and Google Business listing. Selected low-resolution photographs were enhanced with Upscayl and optimized as WebP assets.
